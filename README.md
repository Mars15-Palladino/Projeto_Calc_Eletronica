# Projeto Calc Eletrônica

Calculadora eletrônica desenvolvida em C.

## Objetivo

Desenvolver uma calculadora básica capaz de realizar operações
matemáticas e cálculos voltados à área de eletrônica.


## Status

Em desenvolvimento.

## Funcionalidades

- Operações básicas
- Lei de Ohm
- Potência elétrica
- Resistores em série
- Resistores em paralelo
- Código de cores de resistores
- Conversão de unidades
- Passo a passo dos cálculos

## Plataformas

- Windows
- Linux

## Linguagem

C
