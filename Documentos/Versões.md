# Resumo das Versões do Programa

Este documento apresenta as funcionalidades planejadas para cada versão do Projeto Calc Eletrônica.

---

## V 1.0

### 1. Estrutura e Navegação

* Menu principal
* Submenu de Operações Básicas
* Submenu de Operações Voltadas à Eletrônica
* Opção para voltar ao menu anterior
* Opção para sair do programa

### 2. Operações Básicas

* Adição
* Subtração
* Multiplicação
* Divisão
* Operações com números decimais
* Tratamento de divisão por zero

### 3. Operações Voltadas à Eletrônica

* Lei de Ohm
* Potência elétrica
* Resistores em série
* Resistores em paralelo
* Código de cores de resistores

### 4. Entrada e Validação

* Recebimento de dados pelo teclado
* Validação das opções escolhidas nos menus
* Identificação de entradas inválidas
* Mensagens de erro claras para o usuário

### 5. Exibição dos Resultados

* Apresentação do resultado da operação
* Apresentação das unidades de medida quando aplicável
* Apresentação do passo a passo dos cálculos de eletrônica
* Apresentação das fórmulas utilizadas
* Substituição dos valores informados pelo usuário nas fórmulas
* Apresentação do resultado final

### 6. Compatibilidade

* Windows
* Linux
* Desenvolvimento em linguagem C
